# Create: Mechanica (Create 6.0.10 · MC 1.21.1 · NeoForge 21.1.262)

| Блок | Что делает |
|---|---|
| Редуктор / Мультипликатор | Сквозная коробка передач: на выходе скорость ×0.5 / ×2 (как Gearshift, но с фиксированным передаточным числом). Анимированные валы — из Create. |
| Датчик вращения | Вал, выдающий редстоун 0..15 = \|RPM\|/16. |
| Высотомер | Редстоун 0..15 по ГЛОБАЛЬНОЙ высоте (диапазон в конфиге). |
| Датчик приближения | Редстоун 1..15 — чем ближе цель, тем сильнее. ПКМ пустой рукой: все / враги / игроки. |

## Совместимость с Create Aeronautics
Aeronautics построен на физическом движке Sable: корабль — «подуровень» (sub-level), чьи блоки живут в
plot grid с гигантскими координатами. Поэтому блоки, зависящие от реального положения
(высотомер, датчик приближения), переводят позицию через `SableCompanion.projectOutOfSubLevel`
(см. `compat/SubLevelUtil.java`). Sable Companion вшит в jar (JiJ), без Sable работает заглушка —
Sable/Aeronautics ставить не обязательно. Кинетические блоки — обычные блоки Create и работают
на кораблях без доп. кода.

## Сборка

### Вариант A — GitHub (без установки чего-либо локально)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** → workflow **Build mod jar** запустится сам (или нажмите *Run workflow*).
3. Когда задача завершится, откройте её → раздел **Artifacts** → скачайте `createmechanica-jar`.
4. Внутри архива лежит `createmechanica-0.1.0.jar`.

### Вариант B — локально
1. Установите JDK 21 и Gradle 9.4.1.
2. В папке проекта выполните `gradle build`.
3. Готовый файл: `build/libs/createmechanica-0.1.0.jar`.

### Установка в игру
Положите `createmechanica-0.1.0.jar` в папку `mods` вместе с:
- Create 6.0.10 (`create-1.21.1-6.0.10.jar`) и его зависимостями (Flywheel, Ponder и т.д. — см. страницу Create);
- NeoForge 21.1.262 для Minecraft 1.21.1.

Create Aeronautics и Sable необязательны: без них аддон работает, но высотомер и датчик приближения
учитывают только обычные координаты.
